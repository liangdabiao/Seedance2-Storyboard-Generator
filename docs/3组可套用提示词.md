# 可套用提示词模板合集

## 一、甜宠短剧（适合抖音/小红书）

### 提示词模板
```
角色：甜宠短剧专家
任务：创作3集甜宠短剧
要求：
- 每集1-2分钟
- 包含甜蜜互动和小心动场景
- 男女主CP感强
- 节奏轻快，画面唯美
输出：完整剧本+分镜建议
主题：霸道总裁爱上我
```

### 示例主题
- 霸道总裁爱上我
- 校园青春恋爱物语
- 高冷学霸的秘密心动
- 年下弟弟太会撩

```

0-3秒：[景别]，[运镜]，[画面描述]，[动作]

6-9秒：[景别]，[运镜]，[画面描述]，[高潮动作]
9-12秒：[景别]，[运镜]，[画面描述]，[反转/揭示]
12-15秒：[景别]，[运镜]，[结尾画面]，[留钩]

【声音】[配乐风格] + [音效] + [对白/旁白]
【参考】@图片1 [用途]，@图片2 [用途]
```

### 多角色对话场景提示词
```
真人写实风格，15秒，9:16竖屏，[场景氛围]

0-3秒：全景，固定镜头，[场景建立]，[角色站位]
3-6秒：中景，推镜头，[角色A说话]，【对白】[台词内容]
6-9秒：中景（反打），固定镜头，[角色B反应]，【对白】[台词内容]
9-12秒：特写，推镜头，[关键道具/表情]，【音效】[音效描述]
12-15秒：全景，拉镜头，[结尾画面]，[留钩]

【参考】@图片1 角色A，@图片2 角色B，@图片3 场景
```
