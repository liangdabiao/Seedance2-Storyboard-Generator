# Seedance 分镜生成器

专业的AI脚本和分镜生成系统，用于在Seedance 2.0平台上创建专业的AI视频系列。

## 核心工作流：文-资-视-剪

新一代AI短剧制作体系，取代传统"文图视音剪"流程：

| 阶段 | 核心内容 | 作用 |
|------|----------|------|
| **文** | 剧本创作与分镜拆解 | 提供故事蓝图和施工图纸 |
| **资** | 角色/场景/道具资产库 | 保证成片稳定性与一致性 |
| **视** | 多模态直出视频 | 角色+场景+剧本驱动生成 |
| **剪** | 后期剪辑与画面修补 | 完成最终视听整合 |

## Workflow

按照以下顺序流程将源材料转换为可用于制作的视频脚本：

### 1. 分析输入

**确定输入类型：**
- **完整文本**：需要改编和分集的完整小说/文章
- **大纲**：需要完整脚本开发的简短故事概念

**提取核心元素：**
- 主角和关键角色
- 核心冲突和叙事弧线
- 场景/世界观元素
- 关键情节和情感节拍
- 核心梗/卖点

如果输入模糊或不完整，请提出澄清问题。

### 2. 确认制作参数

**需要询问的基本问题：**

1. **视觉风格**：什么视觉风格？（写实/动画/水墨/科幻/复古/电影感/其他）
2. **时长**：总运行时间？（标准：短剧5集×15秒≈75秒；长剧20集×15秒≈5分钟）
3. **目标平台**：画幅比例？（16:9横屏 / 9:16竖屏 / 2.35:1电影宽屏）
4. **基调**：整体情感基调？（史诗/温馨/悬疑/欢快/忧伤等）
5. **核心梗**：一句话卖点是什么？（绝境反杀/复仇爽剧/治愈温馨/悬疑惊悚等）

记录这些参数，确保在整个过程中一致应用。

### 3. 生成完整剧本结构

**重要：输出必须严格遵循以下格式，符合"好剧本.md"的质量标准。**

#### 3.0 短剧剧本创作套路

**单集结构公式：** 冲突前置 + 情绪拉扯 + 阶段打脸 + 结尾留钩

每集15秒，节奏极快，没有时间做平铺直叙的背景介绍，必须单刀直入。

**AI写剧本提示词模板：**
```
你是一名专业的短剧编剧。请帮我创作一个【类型】短剧剧本。
故事设定如下：【写下剧名、类型、集数、主人公、核心欲望、反派/阻碍、世界观/背景、已有剧情想法】。

请你遵循三幕式结构设置钩子，直接呈现核心冲突，抓住观众。节奏要快，信息密度要高，爽点要多，并在每集结尾留下新的钩子。

要求第一集开头必须设计"黄金三秒"：通过一个强画面、强台词、强冲突、强反差或强悬念，立刻吸引观众眼球，不要平铺直叙介绍背景。第一集还必须介绍世界观、主人公的核心欲望，并尽快抛出核心冲突。每一集都要有一个小反转，一集解决一个矛盾冲突或完成一个情节点，同时留下一个小钩子。可以适当增加支线故事来丰富剧情，但支线必须服务主线。

请在第二幕结尾引出一个颠覆性的大反转，在第三幕揭露真相并给出相对闭合的故事结局。

请先输出"一句话卖点、故事简介、主要人物介绍、分集大纲"。等我确认分集大纲后，再按照常规剧本格式逐集写正式剧本。

正式剧本格式请保持简单清晰：先写集数和本集出场人物，再按场景写"内景/外景、地点、时间"，然后写画面动作和人物台词。台词格式为"人物名：台词"。每集建议3场戏左右，每集结尾必须有钩子。
```

#### 3.1 剧本分析输出格式

```
# [标题] - 剧本

一、核心梗
[两字或短语核心卖点，如：绝境反杀、经典武侠、复仇爽剧]

二、故事梗概
故事背景：[时代、地点、初始处境]
开场冲突：[打破现状的事件，触发冲突]
主角画像：[主角是谁，核心特质，当前状态]
主线事件：[关键情节推进 → 高潮 → 结局]
结局：[最终结果，人物转变]

三、一句话卖点
[带情绪的营销钩子，如：忍无可忍，无须再忍！风雪夜，豹子头林冲长枪出鞘，血溅山神庙！]

四、人物小传
[每个主要角色包含：]

**角色名**
视觉形象：[年龄、外貌细节、服装、关键视觉标记]
身份背景：[社会角色、背景、与主角关系]
核心标签：[2-4个性格标签，如：隐忍不发、悲情英雄、杀神降临]
性格特点：[详细性格描述，弧光转变]
金句：[最能代表角色的台词]

五、剧本大纲
前期（起）：[建立世界观、主角、现状]
中期（承/转）：[冲突发展、复杂化、转折点]
后期（高潮）：[高潮、对抗、情感巅峰]
尾声（收尾）：[结局、余波、主题升华]

六、剧本正文
```

#### 3.2 剧本正文输出格式（每集）

**关键：每集必须严格使用以下格式：**

```
第X集
X-X [日/夜] [内/外] [场景名称]
道具：[关键道具列表]
出场人物：[出场角色列表]

△ 【空镜/开场镜头】[详细镜头描述，含运镜、构图、光影、氛围]
△ [镜头2描述，含具体运镜：推/拉/摇/移/跟/环绕/升降/特写/远景]
△ [镜头3描述 - 逐拍继续]
角色名（内心独白）：[内心独白内容]
△ [反应镜头描述]
角色名（对白/动作描述）：[对白内容]
△ [动作/序列描述]
【字幕：xxx】[需要字幕时添加]
△ [场景继续]
△ 【闪回】[闪回场景描述]
[闪回内容，用△镜头描述]
【闪回结束】
△ [回到现实，反应镜头]
角色名（画外音）：[人物不在画面中的画外音]
△ [高潮动作序列]
△ 【空镜】[结尾氛围镜头]
【字幕：xxx】
```

**剧本格式规则：**

1. **每个镜头以 `△ ` 开头**（三角形+空格）
2. **镜头语言必须具体：**
   - 景别：远景/全景/中景/近景/特写/大特写
   - 运镜：推镜头/拉镜头/摇镜头/移镜头/跟镜头/环绕镜头/升降镜头/希区柯克变焦/一镜到底/手持晃动
   - 组合：`中景推近`、`特写环绕`、`远景俯拍`、`快速推近`、`缓慢拉远`

3. **对白标注：**
   - `角色名（内心独白）` - 角色内心想法，画面中可见角色但嘴未动
   - `角色名（画外音）` - 角色不在当前画面中，声音来自画面外
   - `角色名（惊/怒/喜）` - 带情绪的对白
   - `角色名` - 普通对白

4. **特殊元素：**
   - `【空镜】` - 无人物的氛围/建立镜头
   - `【闪回】` / `【闪回结束】` - 闪回序列
   - `【字幕：xxx】` - 屏幕文字/标题

5. **动作描述格式：**
   - 用 `→` 连续动作：`林冲一枪刺穿差拨胸膛 → 鲜血喷溅 → 雪地染红`
   - 使用情绪化语言：`杀气冲天`、`眼中怒火燃烧`、`浑身颤抖`

6. **感官细节：**
   - 视觉：颜色、光影、构图、氛围
   - 听觉：声音描述融入镜头中
   - 触觉：寒冷、疼痛、质感

### 4. 创建资产生成计划

**对所有视觉资产进行分类和编号：**

| 类别 | 前缀 | 示例 | 描述 |
|----------|--------|---------|-------------|
| 角色 | C01-C99 | C01 林冲·正面全身 | 每个角色多个角度 |
| 场景 | S01-S99 | S01 沧州草料场·雪景 | 关键位置 |
| 道具 | P01-P99 | P01 长枪 | 重要物品 |

#### 4.1 资产构建工作流

**工作流程：**
1. 从剧本/小说中提取人物信息
2. 用大模型生成结构化的人物小传
3. 从人物小传中提炼视觉关键词
4. 把视觉关键词组织成 AI 绘画提示词
5. 迭代到稳定形象后，补充三视图

#### 4.2 资产提示词生成规则

**AI辅助提取人物信息提示词模板：**
```
请先阅读并分析以下短剧剧本：

【在这里粘贴完整剧本】

---
你是一名专业的 AI 出图设计师和短剧视觉资产拆解师。

请根据我提供的故事剧本，完整拆解本剧需要生成的视觉资产，并分别输出【人物资产】【场景资产】【道具资产】的 AI 出图提示词。

整体出图风格要求：
风格须贴合用户在步骤2中选择的视觉风格（写实/动画/水墨/科幻/复古/电影感等）。人物、服装、场景和道具都要贴合剧本的人物身份、时代背景、地域环境、社会阶层和剧情氛围。
```

**一、人物资产要求**

请罗列剧本中所有需要出图的人物角色，并为每个角色生成一条中文 AI 出图提示词。

**人物提示词必须满足以下要求：**
1. 必须是全身正面、纯白背景
2. 必须明确写出"全身站立""正面视角""从头到脚完整入镜"
3. 必须包含鞋子的描述，避免生成半身图
4. 人物不要拿任何东西
5. 双手自然垂落，身体直立
6. 人物没有任何表情，表情中性
7. 必须描述人物的身高、体型、年龄、发型、发色、服装、鞋子、脸型、眼睛
8. 角色形象要符合人物的人种、时代背景、身份职业、发饰和服装设定
9. 成年角色尽量采用接近二八身材比例，形象好看、自然、有镜头感
10. 即便是反派，也不要设计得太丑或太极端；在保留角色特征的前提下，尽量让外形有吸引力
11. 不要出现儿童或老人形象，除非剧本明确需要

**人物提示词格式：**
```
【角色名】
角色定位：
AI 出图提示词：
```

**二、场景资产要求**

请根据剧本中出现的重要地点，罗列所有需要出图的场景，并为每个场景生成 AI 出图提示词。

**场景提示词必须满足以下要求：**
1. 场景中不能出现任何人物
2. 场景风格须贴合用户在步骤2中选择的视觉风格，具有影视剧质感
3. 场景要符合剧本时代、地域、阶层、氛围和剧情功能
4. 每个重要场景至少生成三条提示词：
   - 正打场景图
   - 反打场景图
   - 侧面全景图
5. 正反打要根据角色可能的站位和对话方向来设计，方便后续做分镜参考
6. 侧面全景图要展示完整空间关系，方便理解人物站位和调度
7. 场景中不要出现文字、水印、海报、人物剪影或无关元素

**场景提示词格式：**
```
【场景名】
场景用途：
正打场景图提示词：
反打场景图提示词：
侧面全景图提示词：
```

**三、道具资产要求**

请罗列剧本中所有重要道具，并为每个道具生成一条中文 AI 出图提示词。

**道具提示词必须满足以下要求：**
1. 必须是纯白背景
2. 不要出现任何人物
3. 不要出现真实环境背景
4. 道具要单独展示，主体清晰
5. 道具造型、材质、年代感和使用痕迹要符合剧本设定
6. 如果道具与剧情线索、身份反转、悬念或爽点有关，请在提示词中体现它的重要性
7. 不要出现文字、水印或无关装饰

**道具提示词格式：**
```
【道具名】
道具用途：
AI 出图提示词：
```

**资产生成提示词格式：**
```
### [编号] — [名称]

[风格前缀]，[详细视觉描述（中文）]，[技术规格]

**风格前缀示例：**
- 中国水墨画风格混合动漫赛璐珞渲染
- 电影级写实风格，戏剧性光影
- 3D皮克斯风格动画渲染
- 科幻赛博朋克美学，霓虹灯光

**角色区分：** 为每个角色使用不同的配色方案和视觉标记，确保在所选艺术风格中能够识别。
```

**输出格式：** 带有唯一ID的组织列表，适合复制粘贴到图像生成器中。

#### 4.3 角色三视图及四视图资产

在确定好人物的全身正面图之后，需要生成角色的三视图（正面、侧面、背面）+ 脸部特写，即"四视图"。

**四视图提示词：**
```
生成全身三视图以及一张面部特写。(最左边占满 1/3 的位置是超大的面部特写，右边 2/3 放正视图、侧视图、后视图，二八身材比例)，纯白背景。风格须与用户选择的视觉风格一致。
```

**注意：** 提示词要描述画风风格，不然可能会导致同一图片风格不一样。

#### 4.4 出图比例建议

| 资产类型 | 推荐比例 | 推荐分辨率 |
|----------|----------|------------|
| 角色正面全身照 | 9:16 | 2K |
| 角色三视图/四视图 | 16:9 或 21:9 | 2K |
| 场景图 | 16:9 | 2K |
| 道具图 | 1:1 | 1K/2K |

#### 4.5 角色设计常见问题

1. **服装造型不搭**：古装剧需注意不同历史时期的汉服特色，古偶剧偏向艳丽华贵，仙侠类突出空灵梦幻，武侠类展现潇洒飘逸
2. **人物比例问题**：确保全身照，避免半身图，注意身材比例，采用二八身材比例
3. **美观度问题**：检查缩略图识别度、表情对称性、色彩协调性
4. **其他问题**：不要手持物件、不要带背景、保持站立姿势

**禁止直接使用演员的脸来制作视频**，可以让 AI 参照演员的造型，但绝不能直接采用他们的形象照片。

### 5. 生成 Seedance 2.0 分镜脚本

#### 5.1 Seedance 2.0 分镜提示词生成

**为每集生成以下内容：**

**a. 素材上传列表**
```
| 上传位置 | 素材ID | 素材描述 |
| 图片1 | C01 | 林冲正面全身（角色一致性参考） |
| 图片2 | S01 | 草料场场景参考 |
```

**b. Seedance Prompt（时间轴格式，使用中文）**
```
[风格描述]，15秒，9:16竖屏，[整体氛围]

0-3秒：[场景建立] - [镜头运动]，[详细画面描述]，[氛围营造]

3-6秒：[主体引入/情节发展] - [镜头运动]，[具体动作]，[情绪表达]

6-9秒：[发展/冲突] - [镜头运动]，[关键动作]，[细节特写]

9-12秒：[高潮/转折] - [镜头运动]，[情绪爆发]，[视觉冲击]

12-15秒：[结尾/落版] - [镜头运动]，[最终画面]，[余韵]

【声音】只生成音效，不要生成音乐。不要生成任何字幕。[具体音效描述，如：脚步声、碎裂声、喘息声]

【参考】@图片1 [用途说明]，@图片2 [用途说明]，@图片3 [用途说明]...
```

**c. Ending Frame Description**
- 记录最后一帧内容，确保下一集的连续性
- 包含：主体、背景、光线、构图、氛围

**运镜关键词：** 推镜头/拉镜头/摇镜头/移镜头/跟镜头/环绕镜头/升降镜头/希区柯克变焦/一镜到底/手持晃动

**集数衔接（第2集起）：** 开始提示词使用 `将@视频1延长15s` 并上传上一集作为视频参考。

**更多 Seedance 2.0 使用技巧和模板，请参考 references/seedance-manual.md。**

#### 5.2 素材衔接技巧

1. **抽帧接力**：将上一个视频生成的最后一帧截图，作为下一个视频生成的首帧参考图上传
2. **延长视频**：上传上一个片段，在提示词中要求模型延长视频

#### 5.3 即梦等平台真人审核限制解决方案

针对即梦等平台对真人照片的审核限制，可采用以下方法：
- **局部面部转绘**：利用图片模型对面部进行重绘，降低真实感阈值
- **平台站内洗图**：先在平台内对图片进行轻微修改，增加平台信任度
- **脸部加网格**：在脸部区域添加几何拓扑线框网格
- **脸部特写遮挡**：用小方框遮挡脸部部分区域

#### 5.4 分镜优化

**分镜图的意义**：
1. 降低视频抽卡率：复杂极限镜头先生成分镜图再跑图生视频
2. 残次镜头的兜底补救：通过"抽帧→改图→重新图生视频"优化
3. 空镜头与情绪定格：解决视频大模型难以直出的精美静态画面

**出图改图工具推荐**：
- Nano Banana 系列
- GPT Image 2
- Seedream系列（即梦/豆包图片模型）
- LibTV（聚合平台）

**标准出图提示词公式：**
```
【艺术风格/媒介】+【景别与视角】+【主体描述】+【环境场景】+【光影与色调】+【画质与质感修饰词】
```

**分镜头脚本提示词模板：**
```
你是一位资深电影剪辑师、视觉导演、AI视频分镜设计师。请根据我提供的剧本，拆解成适合 AI 视频制作的分镜头脚本表格，并在表格最后一列直接生成每个分镜的 AI 绘画出图提示词。

【剧本内容】
{在这里粘贴剧本}

## 输出要求
只输出一张 Markdown 表格，不要输出额外说明。表格列为：
| 分镜号 | 景别 | 镜头运动 | 画面内容 | 台词 | 预估时长（秒） | 分镜出图提示词 |

## 分镜规则
1. 将剧本文学描写转化为可拍摄的镜头语言，不要出现"心里想、意识到、突然明白、感到绝望"等无法拍摄的描述
2. 每个分镜时长控制在2-5秒，每集总分镜时长合计13-15秒
3. 景别要有变化，避免连续相同景别，至少包含一次景别切换
4. 动作描述要具体可执行，用→连接连续动作
5. 对白标注声音来源属性：当面说话用"角色名说"，内心想法用"角色名内心独白"，画面外声音用"角色名画外音"
6. 对话场景采用正反打镜头调度，长台词中途切入反应镜头
7. 场景切换或情绪转折处，用空镜配合画外音先导，提升电影感
8. 音效只写明确的环境/动作音效，无明确音效则省略
9. 不要生成音乐，不要生成字幕
```

## 输出格式说明

本工作流产生以下几种输出，它们之间的关系如下：

| 输出 | 所属阶段 | 格式 | 用途 |
|------|----------|------|------|
| **剧本正文** | 文 | △分镜剧本格式（3.2节） | 故事蓝图，是所有后续工作的基础 |
| **资产提示词** | 资 | 编号列表格式（4.2节） | 生成角色/场景/道具图片，供视频生成时作为参考素材 |
| **Seedance分镜提示词** | 视 | 时间轴格式（5.1b节） | 直接粘贴到Seedance 2.0生成视频片段 |
| **分镜出图提示词** | 剪 | 表格格式（5.4节） | 优化/修补残次镜头时先生成分镜图再转视频 |

**流转关系：** 剧本正文 → 提取资产 → 生成资产图片 → 结合剧本+资产图片生成Seedance分镜提示词 → 生成视频 → 如有残次镜头则用分镜出图提示词修补
