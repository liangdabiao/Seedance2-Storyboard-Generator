# Seedance 分镜生成器

专业的AI脚本和分镜生成系统，用于在Seedance 2.0平台上创建专业的AI视频系列。

## 核心工作流：文-资-视-剪

新一代AI短剧制作体系，取代传统"文图视音剪"流程：

| 阶段 | 核心内容 | 作用 |
|------|----------|------|
| **文** | 剧本创作与分镜拆解 | 提供故事蓝图和施工图纸 |
| **资** | 角色/场景/道具资产库 | 保证成片稳定性与一致性 |
| **视** | 多模态直出视频 | 角色+场景+剧本驱动生成 |
| **剪** | 后期剪辑与画面修补 | 完成最终视听整合 |

## Workflow

按照以下顺序流程将源材料转换为可用于制作的视频脚本：

### 1. 分析输入

**确定输入类型：**
- **完整文本**：需要改编和分集的完整小说/文章
- **大纲**：需要完整脚本开发的简短故事概念

**提取核心元素：**
- 主角和关键角色
- 核心冲突和叙事弧线
- 场景/世界观元素
- 关键情节和情感节拍
- 核心梗/卖点

如果输入模糊或不完整，请提出澄清问题。

### 2. 确认制作参数

**需要询问的基本问题：**

1. **视觉风格**：什么视觉风格？（写实/动画/水墨/科幻/复古/电影感/其他）
2. **时长**：总运行时间？（标准：短剧5集×15秒≈75秒；长剧20集×15秒≈5分钟）
3. **目标平台**：画幅比例？（16:9横屏 / 9:16竖屏 / 2.35:1电影宽屏）
4. **基调**：整体情感基调？（史诗/温馨/悬疑/欢快/忧伤等）
5. **核心梗**：一句话卖点是什么？（绝境反杀/复仇爽剧/治愈温馨/悬疑惊悚等）

记录这些参数，确保在整个过程中一致应用。

### 3. 生成完整剧本结构

**重要：输出必须严格遵循以下格式，符合"好剧本.md"的质量标准。**

#### 3.0 短剧剧本创作套路

**单集结构公式：** 冲突前置 + 情绪拉扯 + 阶段打脸 + 结尾留钩

短剧单集通常在1-2分钟，没有时间做平铺直叙的背景介绍，必须单刀直入。

**AI写剧本提示词模板：**
```
你是一名专业的短剧编剧。请帮我创作一个【类型】短剧剧本。
故事设定如下：【写下剧名、类型、集数、主人公、核心欲望、反派/阻碍、世界观/背景、已有剧情想法】。

请你遵循三幕式结构设置钩子，直接呈现核心冲突，抓住观众。节奏要快，信息密度要高，爽点要多，并在每集结尾留下新的钩子。

要求第一集开头必须设计"黄金三秒"：通过一个强画面、强台词、强冲突、强反差或强悬念，立刻吸引观众眼球，不要平铺直叙介绍背景。第一集还必须介绍世界观、主人公的核心欲望，并尽快抛出核心冲突。每一集都要有一个小反转，一集解决一个矛盾冲突或完成一个情节点，同时留下一个小钩子。可以适当增加支线故事来丰富剧情，但支线必须服务主线。

请在第二幕结尾引出一个颠覆性的大反转，在第三幕揭露真相并给出相对闭合的故事结局。

请先输出"一句话卖点、故事简介、主要人物介绍、分集大纲"。等我确认分集大纲后，再按照常规剧本格式逐集写正式剧本。

正式剧本格式请保持简单清晰：先写集数和本集出场人物，再按场景写"内景/外景、地点、时间"，然后写画面动作和人物台词。台词格式为"人物名：台词"。每集建议3场戏左右，每集约1000-1500个汉字左右，每集结尾必须有钩子。
```

#### 3.1 Output Format - Part 1: Story Analysis

```
# [Title] - 剧本

一、核心梗
[Two-word or short phrase core hook, e.g., 绝境反杀、经典武侠、复仇爽剧]

二、故事梗概
故事背景：[Time period, location, initial situation]
开场冲突：[What breaks the status quo, inciting incident]
主角画像：[Who is the protagonist, their core trait, current state]
主线事件：[Key plot progression → climax → resolution]
结局：[Final outcome, character transformation]

三、一句话卖点
[Punchy marketing hook with emotion, e.g., 忍无可忍，无须再忍！风雪夜，豹子头林冲长枪出鞘，血溅山神庙！]

四、人物小传
[For EACH main character include:]

**角色名**
视觉形象：[Age, appearance details, clothing, key visual markers]
身份背景：[Social role, background, relationship to protagonist]
核心标签：[2-4 character traits, e.g., 隐忍不发、悲情英雄、杀神降临]
性格特点：[Detailed personality description, arc transformation]
金句：[Memorable line that captures their essence]

五、剧本大纲
前期（起）：[Setup - establish world, protagonist, status quo]
中期（承/转）：[Conflict development, complications, turning point]
后期（高潮）：[Climax, confrontation, emotional peak]
尾声（收尾）：[Resolution, aftermath, thematic closure]

六、剧本正文
```

#### 3.2 Output Format - Part 2: Script Body (Each Episode)

**CRITICAL: Each episode must use the EXACT format below:**

```
第X集
X-X [日/夜] [内/外] [场景名称]
道具：[List key props]
出场人物：[List characters in scene]

△ 【空镜/开场镜头】[Detailed shot description with camera movement, composition, lighting, atmosphere]
△ [Shot 2 description with specific camera movement: 推/拉/摇/移/跟/环绕/升降/特写/远景]
△ [Shot 3 description - continue for each beat]
角色名（os）：[Interior monologue/voiceover]
△ [Reaction shot description]
角色名（对白/动作描述）：[Spoken dialogue]
△ [Action/sequence description]
【字幕：xxx】[When on-screen text is needed]
△ [Scene continuation]
△ 【闪回】[Flashback scene description]
[Flashback content with △ shots]
【闪回结束】
△ [Return to present, reaction]
角色名（vo）：[Voiceover from off-screen character]
△ [Climactic action sequence]
△ 【空镜】[Closing atmospheric shot]
【字幕：xxx】
```

**Script Format Rules:**

1. **Every shot starts with `△ `** (triangle + space)
2. **Camera language must be specific:**
   - 景别：远景/全景/中景/近景/特写/大特写
   - 运镜：推镜头/拉镜头/摇镜头/移镜头/跟镜头/环绕镜头/升降镜头/希区柯克变焦/一镜到底/手持晃动
   - 组合：`中景推近`、`特写环绕`、`远景俯拍`、`快速推近`、`缓慢拉远`

3. **Dialogue notation:**
   - `角色名（os）` - 画外音/内心独白 (off-screen sound/interior monologue)
   - `角色名（vo）` - 画外音，人物不在画面中 (voiceover)
   - `角色名（惊/怒/喜）` - 带情绪的对白
   - `角色名` - 普通对白

4. **Special elements:**
   - `【空镜】` - Establishing/atmospheric shot without characters
   - `【闪回】` / `【闪回结束】` - Flashback sequence
   - `【字幕：xxx】` - On-screen text/titles

5. **Action description format:**
   - Use `→` for action sequences: `林冲一枪刺穿差拨胸膛 → 鲜血喷溅 → 雪地染红`
   - Use emotive language: `杀气冲天`、`眼中怒火燃烧`、`浑身颤抖`

6. **Sensory details:**
   - Visual: 颜色、光影、构图、氛围
   - Auditory: 声音描述融入镜头中
   - Tactile: 寒冷、疼痛、质感

### 4. 创建资产生成计划

**对所有视觉资产进行分类和编号：**

| 类别 | 前缀 | 示例 | 描述 |
|----------|--------|---------|-------------|
| 角色 | C01-C99 | C01 林冲·正面全身 | 每个角色多个角度 |
| 场景 | S01-S99 | S01 沧州草料场·雪景 | 关键位置 |
| 道具 | P01-P99 | P01 长枪 | 重要物品 |

#### 4.1 资产构建工作流

**工作流程：**
1. 从剧本/小说中提取人物信息
2. 用大模型生成结构化的人物小传
3. 从人物小传中提炼视觉关键词
4. 把视觉关键词组织成 AI 绘画提示词
5. 迭代到稳定形象后，补充三视图

#### 4.2 资产提示词生成规则

**AI辅助提取人物信息提示词模板：**
```
请先阅读并分析以下短剧剧本：

【在这里粘贴完整剧本】

---
你是一名专业的 AI 出图设计师和短剧视觉资产拆解师。

请根据我提供的故事剧本，完整拆解本剧需要生成的视觉资产，并分别输出【人物资产】【场景资产】【道具资产】的 AI 出图提示词。

整体出图风格要求：
真人写实风格，质感自然，符合短剧拍摄审美。人物、服装、场景和道具都要贴合剧本的人物身份、时代背景、地域环境、社会阶层和剧情氛围。
```

**一、人物资产要求**

请罗列剧本中所有需要出图的人物角色，并为每个角色生成一条中文 AI 出图提示词。

**人物提示词必须满足以下要求：**
1. 必须是全身正面、纯白背景
2. 必须明确写出"全身站立""正面视角""从头到脚完整入镜"
3. 必须包含鞋子的描述，避免生成半身图
4. 人物不要拿任何东西
5. 双手自然垂落，身体直立
6. 人物没有任何表情，表情中性
7. 必须描述人物的身高、体型、年龄、发型、发色、服装、鞋子、脸型、眼睛
8. 角色形象要符合人物的人种、时代背景、身份职业、发饰和服装设定
9. 成年角色尽量采用接近二八身材比例，形象好看、自然、有镜头感
10. 即便是反派，也不要设计得太丑或太极端；在保留角色特征的前提下，尽量让外形有吸引力
11. 不要出现儿童或老人形象，除非剧本明确需要

**人物提示词格式：**
```
【角色名】
角色定位：
AI 出图提示词：
```

**二、场景资产要求**

请根据剧本中出现的重要地点，罗列所有需要出图的场景，并为每个场景生成 AI 出图提示词。

**场景提示词必须满足以下要求：**
1. 场景中不能出现任何人物
2. 场景风格必须是真人写实、影视剧质感
3. 场景要符合剧本时代、地域、阶层、氛围和剧情功能
4. 每个重要场景至少生成三条提示词：
   - 正打场景图
   - 反打场景图
   - 侧面全景图
5. 正反打要根据角色可能的站位和对话方向来设计，方便后续做分镜参考
6. 侧面全景图要展示完整空间关系，方便理解人物站位和调度
7. 场景中不要出现文字、水印、海报、人物剪影或无关元素

**场景提示词格式：**
```
【场景名】
场景用途：
正打场景图提示词：
反打场景图提示词：
侧面全景图提示词：
```

**三、道具资产要求**

请罗列剧本中所有重要道具，并为每个道具生成一条中文 AI 出图提示词。

**道具提示词必须满足以下要求：**
1. 必须是纯白背景
2. 不要出现任何人物
3. 不要出现真实环境背景
4. 道具要单独展示，主体清晰
5. 道具造型、材质、年代感和使用痕迹要符合剧本设定
6. 如果道具与剧情线索、身份反转、悬念或爽点有关，请在提示词中体现它的重要性
7. 不要出现文字、水印或无关装饰

**道具提示词格式：**
```
【道具名】
道具用途：
AI 出图提示词：
```

**资产生成提示词格式：**
```
### [编号] — [名称]

[风格前缀]，[详细视觉描述（中文）]，[技术规格]

**风格前缀示例：**
- Chinese ink wash painting style mixed with anime cel-shading
- Cinematic photorealistic style with dramatic lighting
- 3D Pixar-style animation rendering
- Sci-fi cyberpunk aesthetic with neon lighting

**角色区分：** 为每个角色使用不同的配色方案和视觉标记，确保在所选艺术风格中能够识别。
```

**输出格式：** 带有唯一ID的组织列表，适合复制粘贴到图像生成器中。

#### 4.3 角色三视图及四视图资产

在确定好人物的全身正面图之后，需要生成角色的三视图（正面、侧面、背面）+ 脸部特写，即"四视图"。

**四视图提示词：**
```
生成全身三视图以及一张面部特写。(最左边占满 1/3 的位置是超大的面部特写，右边 2/3 放正视图、侧视图、后视图，二八身材比例)，纯白背景。真人写实风格。
```

**注意：** 提示词要描述画风风格，不然可能会导致同一图片风格不一样。

#### 4.4 出图比例建议

| 资产类型 | 推荐比例 | 推荐分辨率 |
|----------|----------|------------|
| 角色正面全身照 | 9:16 | 2K |
| 角色三视图/四视图 | 16:9 或 21:9 | 2K |
| 场景图 | 16:9 | 2K |
| 道具图 | 1:1 | 1K/2K |

#### 4.5 角色设计常见问题

1. **服装造型不搭**：古装剧需注意不同历史时期的汉服特色，古偶剧偏向艳丽华贵，仙侠类突出空灵梦幻，武侠类展现潇洒飘逸
2. **人物比例问题**：确保全身照，避免半身图，注意身材比例，采用二八身材比例
3. **美观度问题**：检查缩略图识别度、表情对称性、色彩协调性
4. **其他问题**：不要手持物件、不要带背景、保持站立姿势

**禁止直接使用演员的脸来制作视频**，可以让 AI 参照演员的造型，但绝不能直接采用他们的形象照片。

### 5. 生成 Seedance 2.0 分镜脚本


#### 5.1 Seedance 2.0全能参考模式使用技巧

**提示词公式：**
```
起手式（固定角色、场景、声音及负面提示词、空间位置关系描述）+ 分镜提示词
```

**完整分镜提示词模板：**
```
【系统指令与角色设定】
你是一位资深的影视剧导演兼专业的AI视频生成提示词工程师。你的任务是将用户提供的"剧本文本"或"分镜头脚本"，转化为可以直接用于AI视频生成工具的、结构化的视频提示词。你需要具备极强的微短剧视听节奏感和剪辑思维。

【核心拆解规则】（请严格遵守以下所有条件）：

段落时长与切割：
每段素材的提示词总时长控制在13-15秒左右（以15秒为基准，根据动作或台词的节奏灵活微调）。不同场景或大情绪转折点，必须切割为不同的素材段落，每段素材使用"---"和"【素材段落 X】"进行分隔。

台词绝对忠实与格式：
台词不能发生任何改动，必须一字不差地保留。不要使用生硬的"台词："标签占位。请直接将台词自然地融入画面描述中，格式为：某某说："台词内容"。

声音属性区分：
严格区分并标注声音的来源属性。当面开口说的话，标注为：某某说："..."。心里想的话，标注为：某某内心独白："..."。人不在画面内但声音出现（或切到别人反应镜头时），标注为：某某画外音："..."。

短剧快节奏剪辑（反应镜头机制）：
如果角色的台词较长，绝对不能用一个长镜头死死盯着说话人。必须按照微短剧的快节奏，在中途切入在场听众的反应镜头（如震惊、贪婪、惊恐、愤怒的特写）。在切入反应镜头时，原台词不能断，需标注为说话人的画外音。

对话的视线与空间逻辑：
对话场景必须采用标准的正反打镜头调度。在激烈的交锋前，或场景刚切换时，可巧妙使用空镜（如建筑外观、景物特写）配合台词画外音先导，提升电影感。

音效处理：
全局设定：只生成音效，不要生成音乐。不要生成任何字幕。提示词结尾只写出明确的环境/动作音效（如：脚步声、碎裂声、喘息声）。若该镜头无明确音效，直接省略音效字段，不要特意写出来。

【标准输出格式模板】
【素材段落 1】
采用[替换为用户指定的视觉风格]，展现一个[填写时间、环境、氛围]，[填写核心事件]的场景。
只生成音效，不要生成音乐。不要生成任何字幕。
0-X秒，[景别]，[运镜/固定]，[详细的画面内容描述，包含人物动作、神态及构图等]。[角色名]说/内心独白/画外音："[一字不差的台词]"。音效：[具体音效描写，无则直接不写此句]。
X-X秒，[景别(标注正反打/反应镜头)]，[运镜/固定]，[详细的画面内容描述]...
【素材段落 2】
采用[替换为用户指定的视觉风格]，展现一个[填写时间、环境、氛围]，[填写核心事件]的场景。
只生成音效，不要生成音乐。不要生成任何字幕。
0-X秒，[景别]...
...
```

**为每集生成：**

#### 5.3 即梦等平台真人审核限制解决方案

针对即梦等平台对真人照片的审核限制，可采用以下方法：
- **局部面部转绘**：利用图片模型对面部进行重绘，降低真实感阈值
- **平台站内洗图**：先在平台内对图片进行轻微修改，增加平台信任度
- **脸部加网格**：在脸部区域添加几何拓扑线框网格
- **脸部特写遮挡**：用小方框遮挡脸部部分区域

#### 5.4 分镜优化

**分镜图的意义**：
1. 降低视频抽卡率：复杂极限镜头先生成分镜图再跑图生视频
2. 残次镜头的兜底补救：通过"抽帧→改图→重新图生视频"优化
3. 空镜头与情绪定格：解决视频大模型难以直出的精美静态画面

**出图改图工具推荐**：
- Nano Banana 系列
- GPT Image 2
- Seedream系列（即梦/豆包图片模型）
- LibTV（聚合平台）

## 分镜规则
1. 将剧本文学描写转化为可拍摄的镜头语言，不要出现"心里想、意识到、突然明白、感到绝望"等无法拍摄的描述

7. 同一场景内的多个分镜，整体色调、光影逻辑、环境氛围必须保持一致

#### 5.5 声音设计

**音乐应用**：
- 去OP/ED化：短剧很少有长篇大论的片头片尾
- 功能性BGM：强调在短时间内迅速拉起观众情绪

**获取BGM的方法**：
1. **AI音乐工具生成**：Suno、Udio、网易天音、海绵音乐等
2. **素材库查找**：剪映音乐素材库（注意版权）

**音效分类**：
- 环境音：建立空间感
- 动作音：增加真实感
- 特殊音效：强调视觉冲击

**音效获取方法**：

**配音工具推荐**：
- DubbingX：多情绪控制强
- MiniMax：拟真度高，适合自然对话

## 脚本写作指南

### 15秒剧集的节奏

| 剧集类型 | 镜头数量 | 节奏 |
|--------------|-----------------|--------|
| 对话/情感 | 3-4个镜头 | 每个镜头4-5秒 |
| 动作/战斗 | 5-7个镜头 | 每个镜头2-3秒 |
| 蒙太奇/序列 | 6-8个镜头 | 每个镜头2秒 |

### 情感 progression

每个15秒剧集应包含：
- **开场 (0-3s)**：建立情感/氛围
- **发展 (3-9s)**：紧张感上升或情节发展
- **高潮 (9-12s)**：情感高峰或关键揭示
- **释放 (12-15s)**：解决或悬念

### 视觉一致性

- 在所有资产提示词中保持一致的艺术风格
- 为每个角色使用独特的视觉标记（颜色、轮廓、配件）
- 在场景描述中参考光线和一天中的时间

## 常见陷阱避免

1. **敏感词**：Seedance可能会拒绝包含某些术语的内容。避免常见触发器或使用替代措辞。
2. **过于复杂的提示词**：长提示词（300+字）可能会导致指令遵循不一致。优先考虑清晰度而非冗长。
3. **缺少连续性**：始终记录结尾帧并验证下一集以匹配的场景开始。
4. **风格不一致**：对所有资产生成提示词应用相同的视觉风格前缀。
5. **模糊的相机语言**：避免使用通用描述如"镜头移动" - 使用具体术语如"推镜头"、"环绕镜头"。
6. **缺少感官细节**：脚本应唤起不仅是视觉，还有声音、温度、质感。
7. **平淡的情感弧线**：每个剧集需要情感进展，而不仅仅是情节点。
